## iOS 实现与优化

- SwiftUI 原生导航、进度、设置、学习足迹与错题列表；PencilKit 草稿支持笔、橡皮、撤销和本地持久化。
- 首页使用模块侧栏、课程网格与宽屏分组；展开学习区按实际可用宽度分为三栏，或题目 / 参考在上、草稿在下。“继续”只在题目栏底部，占 44 pt 触控高度。窄窗口与辅助字体使用工具切换。
- 课程与交互资源离线打包；不依赖官网加载应用，不接入广告、登录或分析 SDK。
- 本地 JSON 原子保存，无法解析时保留恢复副本并显示存储错误。重复提交答案不会重复计分。
- 采用非持久化 WKWebView、限制文件导航、桥接消息校验；评分在原生状态层完成。
- 桌面图标使用用户提供的 `newicon.png`，等比适配为不透明 1024 px 图标。应用内已移除 Logo、应用名称、模块副标题和口号，答题反馈改为直接状态说明。包含隐私清单与开源许可。
- 固定黑墨白纸，避免动态 `.label` 在深色 traits 下持久化为白色。读取旧单色笔记时恢复黑色墨迹，保留笔画路径、蒙版与坐标；草稿模型与画布生命周期分离。

## 草稿问题的定位与验证

先前笔迹数据存在但画面空白。真机绘制文件确认墨色被解析为白色，而画布背景也是白色；这不是笔迹丢失。修复后在真机通过“绘制 → 切换参考 / 草稿 → 旋转 → 关闭并重新启动”的可见像素断言，截图确认黑色笔迹显示。验证使用独立 `WeijiUITesting` 目录，不清空日常学习记录。

最初颜色迁移单元测试把 sRGB 黑色与灰度黑色作对象相等比较，出现误报；改为比较 RGBA 数值后 7 项全部通过。`Weiji-final-device-tests.xcresult` 的 UI 测试通过、单元测试有该误报；最终单元结果以 `Weiji-unit-build2.xcresult` 为准。
