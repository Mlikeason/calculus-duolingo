## iOS 实现与优化

- SwiftUI 原生导航、进度、设置、学习足迹与错题列表；PencilKit 草稿支持笔、橡皮、撤销和本地持久化。
- 根据实际可用空间和 size class 布局，展开时双栏，窄窗口与辅助字体使用单栏。系统导航栏与安全区域负责 Duo 的非对称边缘。
- 课程与交互资源离线打包；不依赖官网加载应用，不接入广告、登录或分析 SDK。
- 本地 JSON 原子保存，无法解析时保留恢复副本并显示存储错误。重复提交答案不会重复计分。
- 采用非持久化 WKWebView、限制文件导航、桥接消息校验；评分在原生状态层完成。
- 独立原创矢量构图应用图标，1024 px，包含隐私清单与开源许可。
